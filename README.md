#  Calculadora de Índice de Masa Corporal (IMC)

##  Descripción del proyecto

Este proyecto consiste en un programa desarrollado en lenguaje C que permite
calcular el Índice de Masa Corporal (IMC) de una persona utilizando su peso
y altura.

El programa también clasifica el resultado obtenido en diferentes categorías:
bajo peso, peso normal, sobrepeso u obesidad.

##  Problema que resuelve

El programa permite obtener de manera rápida el índice de masa corporal
de una persona y conocer la categoría correspondiente según el resultado
obtenido.

Esto sirve como una herramienta básica para comprender cómo se puede utilizar
la programación para realizar cálculos y tomar decisiones a partir de los
datos introducidos por el usuario.


##  Tecnologías utilizadas

- Lenguaje C
- Visual Studio Code
- Compilador GCC
- GitHub

##  Funcionamiento

El programa solicita al usuario dos datos:

1. Peso en kilogramos.
2. Altura en metros.

Después calcula el IMC utilizando la siguiente fórmula:

IMC = peso / (altura × altura)

Finalmente, el programa muestra el resultado y determina su clasificación.

### Clasificaciones utilizadas

| IMC | Clasificación |
|---|---|
| Menor de 18.5 | Bajo peso |
| 18.5 - 24.9 | Peso normal |
| 25.0 - 29.9 | Sobrepeso |
| 30.0 o más | Obesidad |

##  Instalación y ejecución

### Requisitos

Para ejecutar el programa se necesita:

- Un compilador de C, como GCC.
- Un editor de código, como Visual Studio Code.

### Pasos

1. Descargar o clonar este repositorio.
2. Abrir el archivo `IMC.c`.
3. Compilar el programa utilizando un compilador de C.
4. Ejecutar el programa.
5. Introducir el peso en kilogramos.
6. Introducir la altura en metros.
7. El programa mostrará el IMC y su clasificación.
